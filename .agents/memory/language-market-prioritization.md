---
name: Language market prioritization
description: User guidance for choosing future FocusFlow translations based on audience language preference rather than country alone.
---

For FocusFlow's India audience, most users prefer reading in English; do not infer Hindi preference from install location alone.

**Why:** the user corrected localization recommendations that treated Indian install counts as Hindi demand.

**How to apply:** weigh likely reading preference and product audience ahead of country counts when prioritizing new locales; treat country as a rough signal only.
